# 지금 나가 - Icon Assets

## 1. 개요

지금 나가 프로젝트에서 사용하는 UI 아이콘 리소스를 관리하는 폴더입니다.

- 형식: SVG
- 디자인 도구: Figma
- 아이콘 개수: 52개
- 용도: 프론트엔드 UI 구현에 필요한 아이콘 리소스 제공

## 3. 사용 규칙

- 아이콘 파일은 SVG 형식으로 사용합니다.
- 파일명은 영문 소문자와 언더바(_)를 기본으로 사용합니다.
- 아이콘의 색상과 크기는 화면 디자인 기준에 맞춰 적용합니다.
- 아이콘 추가 또는 수정 시 해당 목록도 함께 업데이트합니다.
- 기존 아이콘을 수정할 경우 동일한 파일명을 유지하여 관리합니다.
