## 🎨 지금나가 Design

약속을 잡는 순간부터 목적지에 도착할 때까지
사용자가 자신의 이동 상황과 친구들의 도착 정보를
쉽게 확인할 수 있도록 서비스의 UI/UX를 설계합니다.

복잡한 위치 정보와 이동 데이터를 직관적으로 전달하고,
사용자가 약속 시간과 이동 상황을 한눈에 파악할 수 있도록
서비스 전반의 사용자 경험과 디자인을 담당합니다.

---

## 주요 작업

- 서비스 전체 사용자 흐름 설계
- 약속 생성 및 참여 UX 설계
- 약속 장소 선택 화면 설계
- 지도 및 위치 정보 UI 설계
- 실시간 위치 및 ETA 정보 시각화
- 이동 상태 및 약속 상태 UI 설계
- 모바일 UI 디자인
- 디자인 시스템 및 컴포넌트 설계
- 프로토타입 제작
- 사용자 경험 개선

---

## 역할

Design은 다음 기능을 담당합니다.

- 서비스 UI/UX 설계
- 사용자 Flow 및 화면 구조 설계
- 와이어프레임 제작
- 모바일 화면 디자인
- 디자인 시스템 구축
- UI 컴포넌트 설계
- 프로토타입 제작
- Frontend 개발을 위한 디자인 산출물 제공
